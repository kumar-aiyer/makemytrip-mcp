# Live find-bug log

Every bug found by the live testing harness (Cline + makemytrip MCP tools) goes here.
One block per bug. Copy the block, fill it in, keep it — it survives across sessions.

---

## Template

```markdown
### BUG-<n>: <short title>

- **Found:** YYYY-MM-DD (phase)
- **Call:** `<tool>(<key args>)`
- **Expected:** <what the docs/contract say should happen>
- **Actual:** <what actually happened>
- **kind:** <error kind, or "none">
- **tier/latency:** tier N, Xms
- **Root cause:** <what you found>
- **Fix:** <commit / file / change>
- **Regression test added?:** yes/no + name
```
